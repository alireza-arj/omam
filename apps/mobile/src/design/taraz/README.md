# Taraz + HeroUI

Taraz is OMAM's theme and localization layer over [HeroUI Native](https://heroui.com/docs/native/getting-started/quick-start).
Screens keep importing from `src/design/taraz`; the shared adapters render the real HeroUI components.

## Components

| OMAM component | HeroUI implementation |
| --- | --- |
| Button, IconButton | Button, Spinner |
| Input | TextField, Label, Input, InputGroup, TextArea, Description, FieldError |
| Card | Card, PressableFeedback |
| Badge, Tag | Chip |
| Avatar | Avatar.Image, Avatar.Fallback |
| SegmentedControl, TabBar | Tabs |
| Accordion | Accordion |
| ConfirmDialog | Dialog, Portal, Overlay |
| Toast | Toast and the provider's toast queue |
| Divider, Skeleton | Separator, Skeleton |
| ListRow | ListGroup |
| Text | HeroUI Text with localized type roles |
| Glass | GlassView |
| ProgressBar | Surface with a read-only progress track |

Screen, PageHeader, EmptyState, Stat and the session dial remain app-specific compositions; HeroUI Native has no equivalent for the time-tracking dial or calendar reports. Icons continue to use Lucide.

## Setup

- `heroui-native` is pinned to `1.0.9`, compatible with the project's Expo 54 / React Native 0.81 stack.
- Metro uses `withUniwindConfig`, and `global.css` imports Tailwind 4, Uniwind and HeroUI styles. NativeWind and its Babel preset are removed.
- `HeroUIProvider` belongs under GestureHandlerRootView and SafeAreaProvider and above the startup/loading screens and navigator.
- `hero-ui-provider.tsx` maps the existing light/dark tokens to HeroUI CSS variables and synchronizes the saved theme. Colors remain defined in `tokens.ts`.
- Both Metro entry points use the same stylesheet; `uniwind-env.d.ts` is generated by Metro.

## Conventions

- Import components and tokens from this folder. Add missing colors, spacing, type roles, radii and durations to `tokens.ts`.
- Crimson marks actions and active states; success, warning and info communicate status.
- Every visible string comes from `@omam/i18n`. Use sentence case and verb labels.
- Persian uses Vazirmatn, no Latin tracking, and an explicit RTL layout scope. Numeric inputs and time ranges retain LTR direction. Input decorators share the input's direction so suffixes cannot overlap values.
- Respect system text scaling and reduced motion; interactive controls have a minimum 44-point target.
- On web, ConfirmDialog mounts HeroUI content inside React Native Modal to contain keyboard focus and support Escape. Native platforms use HeroUI's Portal.
- Web CSS hides HeroUI's invisible toast measurement copy from keyboard navigation and screen readers while preserving its layout measurements.
- Use HeroUI granular exports inside the adapters to keep unused components out of the bundle.
- Keep session data, payroll rules, calendar arithmetic and offline synchronization in their existing providers.

## Verification

Run `bun run typecheck`, `bun run test`, `bun run test:smoke` against a development API, and `bun run build:mobile`. Verify forms, tabs, dialogs, toasts, both languages and both themes in Expo. HeroUI documents its Native package primarily for iOS/Android; exercise the Expo web output separately after upgrades. The admin panel uses `@heroui/react` and `@heroui/styles` instead.
